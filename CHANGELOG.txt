ARIA FOR IPHONE AND IPAD - VERSION HISTORY
==========================================

Version 1.3.0
Created: 2026-08-29

Added:
- Added an Add to Playlist option to the three-dot song menu on iPhone.
- Reused the playlist picker so songs can be added to an existing playlist or used to create a new one.


Version 1.2.2
Created: 2026-08-29

Changed:
- Advanced the shared Aria release from 1.2.1 to 1.2.2 for the Mac karaoke lyrics refinement.


Version 1.2.1
Created: 2026-08-28

Fixed:
- Fixed user-created playlists disappearing after the app restarts or refreshes the catalog.
- Saved playlist names, stable IDs, song membership, and track snapshots atomically.
- Reconnected saved playlist songs to refreshed server metadata without overwriting playlists.

Changed:
- Advanced the shared Aria release from 1.2.0 to 1.2.1.


Version 1.2.0
Created: 2026-08-28

Added:
- Added a Lyrics button to Now Playing on iPhone and iPad.
- Added synchronized lyric highlighting, automatic scrolling, and tap-to-seek.
- Added plain-lyrics, instrumental, unavailable, loading, and retry states.

Changed:
- Advanced the shared Aria release from 1.1.4 to 1.2.0 for the lyrics feature.


Version 1.1.4
Created: 2026-08-19

Added:
- Added this permanent per-version history with creation dates and release notes.

Changed:
- Advanced the shared Aria release from 1.1.3 to 1.1.4.
- Updated the repository rules so every future push records its version here.


Version 1.1.3
Created: 2026-08-19

Added:
- Added the universal iPhone and iPad music library and player experience.
- Added the dedicated iPad split-view layout and sidebar navigation.
- Added YouTube Music album search, repeatable result loading, and downloads.
- Added downloaded-album detection so existing versions cannot be downloaded again.
- Added a visible release number in the iPhone Library and iPad sidebar.

Changed:
- Connected downloads, catalog refreshes, artwork, and playback to the Fedora server.
- Synchronized the Apple app and server release number at 1.1.3.

Note: This was the first release recorded after version history was introduced.
